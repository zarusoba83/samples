# 株主優待クーポン管理アプリ

URLベースのクーポンコードを発行・管理する株主優待システムです。

## 機能

- **株主管理**: 株主の登録・編集・削除
- **キャンペーン管理**: 優待キャンペーンの作成・クーポン一括発行
- **クーポン管理**: 発行済みクーポンの一覧・詳細・無効化
- **公開クーポンページ**: 株主がURLにアクセスしてクーポンを確認・使用

## セットアップ

```bash
cd ShareholderCouponApp
npm install
cp .env.example .env
# .env を編集して設定を変更
npm start
```

## 使い方

1. `http://localhost:3000/admin` にアクセス
2. 初期ログイン情報: `admin` / `changeme`（`.env`で変更可）
3. 株主を登録 → キャンペーンを作成 → クーポン一括発行
4. 各クーポンのURLを株主にメール等で送付
5. 株主がURLにアクセスしてクーポンを使用

## クーポンURL形式

```
http://your-domain.com/coupon/{64文字のランダムトークン}
```

## セキュリティ

- トークンは `crypto.randomBytes(32)` による256bitランダム値
- クーポン使用は条件付きUPDATEで二重使用を防止
- レートリミット（15分間30リクエスト/IP）
- 管理者パスワードはbcryptハッシュ
